# Groomora Android Studio Starter

Initial Compose Multiplatform starter for the Groomora customer app.

## Includes
- Kotlin Multiplatform
- Compose Multiplatform
- Android target
- iOS target declarations
- Shared UI
- Groomora starter theme
- Working starter home screen
- Feature-first package placeholders
- REQUIREMENTS.md and ARCHITECTURE.md

Open the Groomora folder in Android Studio and sync Gradle.
